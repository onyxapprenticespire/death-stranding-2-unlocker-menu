**Death Stranding 2 Unlocker Menu** is a curated list of Death Stranding 2 open-source tools:

## ✨ Features

### ESP
- Cargo Viewer — visualize cargo weight and balance
- Route Planner — plan optimal delivery routes
- Replay Notes — record and review delivery runs
- Time Control — adjust game speed for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse equipment, upgrades, and cosmetics
- Custom Skin Notes — organize character and vehicle cosmetics
- Highlight Interactables — improved visibility of key objects

### Aimbot
- Base Layout Notes — segment study on any base layout
- Resource Tracker — monitor materials and supplies
- Build Buffer Notes — chain complex constructions in the editor
